    Key Concepts¶

    The architectures and techniques that define modern ML. Each section: what it is, the key insight, and when to use it.

    Attention & Transformers¶

    Attention computes a weighted sum of values where the weights come from the similarity between queries and keys: Attention(Q, K, V) = softmax(QK^T / √d_k)V. The √d_k scaling prevents softmax from saturating in high dimensions. Multi-head attention runs multiple attention operations in parallel with different learned projections, letting the model attend to different relationship types simultaneously. The Transformer architecture stacks self-attention layers with feedforward networks, layer normalization, and residual connections.

    Key insight: Attention lets every token directly interact with every other token in a single layer, regardless of distance. This solves the long-range dependency problem that crippled RNNs.

    Use when: You need to model relationships between elements in a sequence (or set). This is the default architecture for language, and increasingly for vision and multimodal tasks.

    Vision Models¶

    ConvNets use spatial inductive biases — local connectivity and translation equivariance — built into the architecture via convolution. Vision Transformers (ViT) split images into patches, treat them as tokens, and apply standard Transformer attention with no built-in spatial bias. ConvNeXt modernizes ConvNets with Transformer-era design choices (larger kernels, fewer normalization layers, GELU activations) and matches ViT performance while keeping the efficiency of convolutions.

    Key insight: ViT needs more data to learn spatial relationships that ConvNets get for free, but with enough data, the flexibility of attention wins. ConvNeXt shows that many of ViT's gains came from training recipes, not attention itself.

    Use when: ConvNeXt or EfficientNet for smaller datasets or when you need efficiency. ViT when you have large-scale data or need to integrate with other Transformer-based components.

    CLIP¶

    CLIP (Contrastive Language-Image Pre-training) trains a text encoder and image encoder jointly using contrastive learning. Given a batch of (image, text) pairs, it learns to maximize the cosine similarity for matching pairs and minimize it for non-matching pairs. The result is a shared embedding space where text and images with similar semantics are nearby.

    Key insight: By training on 400M image-text pairs from the internet, CLIP learns visual concepts from natural language supervision rather than fixed categories. It provides zero-shot transfer — classify images using text descriptions of categories it's never explicitly trained on.

    Use when: You need a vision backbone that understands semantic concepts, zero-shot classification, image-text retrieval, or a shared embedding space for multimodal tasks.

    Diffusion Models¶

    Diffusion models learn to generate data by reversing a gradual noising process. The forward process adds Gaussian noise over T timesteps until the data becomes pure noise. The model learns the reverse: given a noisy sample and a timestep, predict the noise that was added. At generation time, start from pure noise and iteratively denoise. The training objective simplifies to a weighted MSE between predicted and actual noise.

    Key insight: Instead of learning to generate data in one shot (hard), diffusion breaks generation into many small denoising steps (easy). Each step only needs to remove a little noise, making each sub-problem tractable.

    Use when: High-quality image/video generation, or anywhere you need to model complex distributions (action prediction in robotics, molecular design, audio synthesis).

    RL Basics¶

    Reinforcement learning trains an agent to maximize cumulative reward by interacting with an environment. Policy gradient methods directly optimize the policy (action probabilities) by estimating the gradient of expected reward. PPO (Proximal Policy Optimization) clips the policy update to prevent destructively large steps, making training stable. GRPO (Group Relative Policy Optimization) skips the value function entirely — it samples multiple outputs, scores them with a reward function, and uses the group's relative ranking as the advantage signal.

    Key insight: RL is powerful because it optimizes for outcomes rather than imitating demonstrations. But it's notoriously unstable — reward shaping (designing rewards that guide learning without introducing bias) is often the hardest part.

    Use when: You need to optimize for a metric that can't be expressed as a differentiable loss — RLHF for language models, game playing, robotics control, or any sequential decision problem.

    LoRA & PEFT¶

    LoRA (Low-Rank Adaptation) freezes the pretrained model and adds small trainable rank-decomposition matrices: instead of updating a d×d weight matrix W, it learns W + BA where B is d×r and A is r×d with r << d (typically 4-64). This reduces trainable parameters by 100-1000× while matching full fine-tuning performance on most tasks. Other PEFT methods include prefix tuning (learnable prompt tokens) and adapters (small bottleneck layers inserted between frozen layers).

    Key insight: Weight updates during fine-tuning have low intrinsic rank — most of the information is captured in a small subspace. LoRA exploits this structure directly.

    Use when: Fine-tuning large models with limited GPU memory, serving multiple task-specific variants from one base model, or when you need to adapt quickly without catastrophic forgetting.

    Distillation¶

    Knowledge distillation trains a smaller "student" model to mimic a larger "teacher" model's outputs rather than learning from hard labels alone. The student trains on the teacher's soft probability distributions (softmax outputs with temperature scaling), which contain richer information — for example, a teacher might assign 0.7 to "cat" and 0.2 to "tiger," teaching the student about inter-class similarity. The total loss combines the distillation loss (KL divergence between teacher and student outputs) with the standard task loss.

    Key insight: The teacher's soft outputs carry "dark knowledge" about relationships between classes and uncertainty that hard labels don't capture. A small model trained with distillation consistently outperforms the same model trained from scratch.

    Use when: You need to deploy a smaller, faster model while retaining most of a large model's quality. Common in production: distill a massive model into something that fits on a phone or meets latency requirements.

    FiLM Conditioning¶

    FiLM (Feature-wise Linear Modulation) conditions a neural network on auxiliary information by learning to scale and shift intermediate feature maps: FiLM(x) = γ(z) ⊙ x + β(z) where γ and β are predicted from the conditioning input z. A small conditioning network takes the auxiliary signal (timestep, text embedding, task ID) and outputs per-channel scale and shift parameters that modulate the main network's activations.

    Key insight: FiLM is extremely parameter-efficient — you only add two vectors per layer — yet it gives the conditioning signal deep control over the network's computation. The modulation can selectively amplify, suppress, or shift entire feature channels.

    Use when: You need to condition a model on auxiliary information (timestep in diffusion, language embedding in vision-language models, task descriptor in multi-task learning). Lighter weight than cross-attention.
