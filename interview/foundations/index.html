    Foundations¶

    The core mechanics of how neural networks learn. Not a textbook — the key insights only.

    What Is a Neural Network (Really)¶

    A neural network is a function approximator built from layers of linear transformations followed by nonlinear activation functions. Each layer computes y = activation(Wx + b) where W (weights) and b (bias) are learnable parameters.

    Key insight: Without activations, stacking layers just gives you another linear function — no more expressive than a single layer. The nonlinearity (ReLU, GELU, etc.) is what lets networks approximate any continuous function given enough parameters (universal approximation theorem).

    A neural network with one hidden layer can theoretically approximate anything, but in practice, deeper networks learn hierarchical features more efficiently: early layers learn edges, middle layers learn textures, later layers learn objects.

    What Is Training¶

    Training = finding parameter values that minimize a loss function over your data.

    Gradient descent: Compute the gradient of the loss with respect to every parameter. The gradient tells you which direction increases the loss — step in the opposite direction. Repeat.

    1
    θ_new = θ_old - lr × ∇L(θ)

    Stochastic gradient descent (SGD): Don't compute the gradient over the entire dataset (too expensive). Sample a mini-batch (32, 64, 256 examples), compute the gradient on that, and step. The noise from sampling actually helps escape local minima.

    Key insight: Training is optimization over a loss landscape. The loss function defines what to learn. The optimizer defines how to navigate. The data defines from what.

    What Is a Loss Function¶

    The loss function measures how wrong your model's predictions are. Training minimizes this number.

    Mean Squared Error (MSE): L = (1/n) Σ(y_pred - y_true)². Used for regression. Penalizes large errors quadratically — big mistakes matter more.

    Cross-Entropy Loss: L = -Σ y_true × log(y_pred). Used for classification. Measures how far the predicted probability distribution is from the true distribution.

    Connection to information theory: Cross-entropy = entropy + KL divergence. Minimizing cross-entropy is the same as minimizing KL divergence between predicted and true distributions, which is the same as maximum likelihood estimation (MLE). These are all the same thing viewed from different angles.

    Key insight: Your loss function encodes your entire learning objective. A bad loss function means optimal training gives you the wrong model. Choosing the right loss is often more important than choosing the right architecture.

    What Is Backpropagation¶

    Backprop is just the chain rule applied systematically through a computation graph.

    The chain rule: If L = f(g(h(x))), then dL/dx = dL/df × df/dg × dg/dh × dh/dx. Each layer computes its local gradient and passes it backward.

    Computation graph: Every operation your model performs (matmul, add, ReLU, softmax) is a node in a directed acyclic graph. The forward pass computes the output. The backward pass walks the graph in reverse, multiplying local gradients.

    In practice:

    1. Forward pass: compute output and loss
    2. Backward pass: compute gradient of loss w.r.t. every parameter
    3. Update: optimizer steps each parameter using its gradient

    Key insight: Backprop is efficient because it reuses intermediate computations. Computing all gradients costs roughly 2-3× the forward pass — not one pass per parameter. This is what makes training neural networks feasible.

    What Is an Optimizer¶

    The optimizer decides how to update parameters given gradients. Vanilla SGD just steps proportionally to the gradient. Modern optimizers are smarter.

    SGD with momentum: Keep a running average of past gradients. This smooths out noise and accelerates through narrow valleys in the loss landscape.

    Adam (Adaptive Moment Estimation): Maintains per-parameter learning rates using first moment (mean) and second moment (variance) of gradients. Parameters with consistently large gradients get smaller updates; parameters with small, noisy gradients get larger updates.

    AdamW: Adam with decoupled weight decay. Standard Adam applies weight decay through the gradient, which interacts badly with the adaptive learning rate. AdamW applies it directly to the weights, giving proper L2 regularization. This is what you should use by default.

    Key insight: Adaptive learning rates (Adam, AdamW) work well because different parameters need different step sizes. A parameter in an early layer and a parameter in the final layer face very different gradient landscapes.

    Typical defaults: AdamW with lr=1e-4 to 3e-4, betas=(0.9, 0.999), weight_decay=0.01. Use a warmup schedule (linear warmup for ~5-10% of training, then cosine decay).

    What Is Regularization¶

    Regularization prevents overfitting — when your model memorizes training data instead of learning generalizable patterns.

    Dropout: During training, randomly zero out neurons with probability p (typically 0.1-0.3). This forces the network to not rely on any single neuron and builds redundancy. At inference, use all neurons but scale by (1-p).

    Weight decay (L2 regularization): Add λ × ||W||² to the loss, penalizing large weights. Keeps parameters small, which acts as a soft constraint on model complexity. In AdamW, this is applied directly to weights rather than through the gradient.

    Early stopping: Monitor validation loss during training. When it stops improving (or starts increasing while training loss keeps decreasing), stop. The gap between training and validation loss is your overfitting signal.

    Data augmentation: Transform training data (crop, flip, rotate, add noise) to artificially increase diversity. The model must learn features robust to these transformations.

    Key insight: Regularization is about the bias-variance tradeoff. Too little capacity or too much regularization → underfitting (can't learn the pattern). Too much capacity or too little regularization → overfitting (memorizes noise). The sweet spot is where your model generalizes.
