# ML Interview Prep

Built for a self-taught SWE preparing for AI lab interviews. 14 coding drills + interview guide, all mapped to a real VLA project.

## Sections

### [Coding Drills](drills/index.md)

Hands-on PyTorch implementations covering the core ML building blocks: attention, backprop, LoRA, diffusion, training loops, and more. Each drill is a focused exercise you can complete in 15-30 minutes.

### [Interview Guide](interview/index.md)

A complete interview prep guide that maps your VLA project experience to the formal language interviewers expect. Covers your pitch, core concepts, likely questions, math intuitions, study plan, and positioning strategy.

## Quick Start

1. **Read the interview guide first** — start with the [pitch](interview/index.mdpitch.md) to nail your project narrative
2. **Work through coding drills** — implement the fundamentals so you can explain them from experience
3. **Follow the study plan** — the [week-by-week schedule](interview/index.mdstudy-plan.md) prioritizes what matters most
4. **Practice out loud** — saying things activates verbal recall differently than reading silently
